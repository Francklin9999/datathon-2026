# GLEIF Golden Copy metadata and bounded intraday delta (SRC-044)

`GET /v1/intelligence/gleif-golden/metadata` returns five current official CSV archive descriptors with byte sizes, record counts, format and content timestamp. Full data is not downloaded. On 2026-11-15 the full LEI archive was 509,685,576 compressed bytes, versus 247,969 bytes for the intraday update. Source metadata is captured and SHA-256 versioned per session.

`POST /v1/intelligence/gleif-golden/delta/{lei}` obtains only the current intraday LEI-CSV ZIP after exact checksum validation. The fixed GLEIF host/storage path is checked; the compressed archive is limited to 2 MB, expanded CSV to 12 MB and 20,000 rows, with one member, duplicate-header checks, validated record count, exact LEI lookup and duplicate rejection. Source bytes and metadata are stored immutably under the existing session-owned cache with original hash, source URL, version and conservative retrieval availability. A captured record is read back only for its owner and after its capture (`golden_copy.latest_entity`, which rechecks the original archive hash and reparses the selected row); it reaches the UI through `GET /v1/intelligence/relationships`. The separate `GET /v1/intelligence/gleif-golden/entity/{lei}` route had no consumer and was removed in the 2026-11-15 wiring audit. `GoldenCopy.tsx` provides source metadata and exact-LEI lookup in Markets.

The real 2026-11-15 source metadata, 247,969-byte intraday delta, and selected official LEI `010CMKZ3VON21WF2ZD45` are retained under `docs/evidence/parallel/agent-2/security/gleif-golden-*`. The API scanned all 1,988 reported rows and extracted the exact row. The captured entity record enriches an exact LEI node in the issuer relationship graph; it does not create a security-to-issuer or ownership relationship. Graph historical mode only includes it after its capture.

GLEIF describes the underlying datasets and content-date updates at https://www.gleif.org/en/lei-data/gleif-golden-copy and the Golden Copy API and delta periods in https://www.gleif.org/media/pages/lei-data/gleif-golden-copy/bcfd8becc7-1746445121/2022-02-23_gleif-golden-copy-and-delta-files_v2.2-final.pdf. GLEIF LEI data access terms are https://www.gleif.org/en/meta/lei-data-terms-of-use. The metadata `publish_date` is treated as content time; no actual publication time is invented. The intraday delta is changes since the preceding copy; absence in it does not prove an LEI does not exist. Source file and metadata are not a complete Golden Copy import.
