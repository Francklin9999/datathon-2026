# Public DeFi API work (Agent 2)

## Status and scope

- **SRC-064, DEX Screener:** exact-chain/exact-pool adapter, selected observation API, session-owned immutable source capture and Markets card implemented. Public API probe on 2026-11-15 returned HTTP 200 for the Ethereum 0x88e6… pool; its exact chain, pool and base/quote token addresses passed normalization. The probe was kept only in memory/temporary scratch and removed; it is not a retained production capture. Runtime defaults to disabled until `APLOMB_DEXSCREENER_RIGHTS_CONFIRMED=true` records operator review for this use. The provider's API terms allow commercial and non-commercial use but prohibit certain competitive products and unauthorized third-party API provision. No unrestricted raw feed or raw-capture HTTP endpoint is exposed. Official [API reference](https://docs.dexscreener.com/api/reference) and [terms](https://docs.dexscreener.com/api/api-terms-and-conditions).
- **SRC-065 / MASTER-007, DefiLlama:** exact provider slug **and** returned provider ID adapter, selected TVL-by-chain observation API and Markets card implemented with synthetic example only. Default disabled until `APLOMB_DEFILLAMA_WRITTEN_DATA_RIGHTS=true` asserts that specific written permission for copying, retention and display applies. Its [terms](https://defillama.com/terms) disallow copying/mirroring and republication without permission, while its [API docs](https://api-docs.defillama.com/) show a no-key free API. The public yield endpoints shut down 2026-11-13; no removed yield endpoint is called. Source rights and live product use remain externally blocked until permission is obtained.
- **SRC-066, GeckoTerminal:** deferred. CoinGecko documents a [keyless public API](https://support.coingecko.com/articles/6867086195-does-geckoterminal-have-an-api) but its [licensing guidance](https://support.coingecko.com/articles/1043089972-what-are-the-differences-between-commercial-and-custom-licenses) ties caching/storage to an active paid plan and reserves redistribution rights; the owner directed that paid sources be deferred. No call, capture or connector claims this source integrated.

## Interfaces and behavior

- `backend/aplomb/intelligence/defi_sources.py`: fixed HTTPS origins, timeout/size cap and redirects disabled; exact EVM or Solana pool identities, fixed chain allowlist, exact returned chain/pool identity, separately checked token addresses, provider values kept as finite decimal strings. DefiLlama protocol id must match source-provided `id` exactly; the slug alone never establishes issuer/security identity. No fuzzy joins.
- A capture is stored in existing `cache`, partitioned by hashed session and keyed by URL+provider+payload SHA-256. Raw bytes decoded as UTF-8 plus normalized values and capture metadata are immutable and idempotently reused; no capture can be returned through another session. Duplicate capture returns its original retrieval time.
- DEX outputs provider-reported price, liquidity, volume and other estimate fields. `available_at` is retrieval time, with unknown publication date; historical availability before retrieval is not claimed. DefiLlama chain TVL fields are provider estimates and not portfolio value, revenues or verified on-chain measurements. No token symbol, token contract or protocol label is treated as an issuer/security mapping.
- `backend/aplomb/intelligence/defi_routes.py`: `GET /v1/intelligence/defi/sources`, `/pair/{chain}/{pool}`, `/protocol/{slug}?provider_id=`. All require a session; source calls limited to 6 per minute per session, missing rights/provider failures are returned as standard unavailable responses. This response uses branch-local snake_case JSON and should be added to the common typed contract during integration.
- `web/src/features/markets/DefiResearch.tsx`: bilingual Markets card showing source terms, rights status, exact identifiers, selected values, source hash, availability and restrictions. Buttons remain disabled until the server reports the applicable source configured.
