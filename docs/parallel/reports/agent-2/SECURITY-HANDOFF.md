# Security identity and source intelligence

Implemented: bounded, paginated exact GLEIF ISIN-to-LEI lookup inspects actual row pairs, captures matching raw source page in a session-owned partition, and exposes the exact pair through `GET /v1/intelligence/relationships` and `POST /v1/intelligence/master/adapters/gleif-pair`, which Markets calls. (The earlier standalone `/v1/intelligence/security-issuer` route had no consumer and was removed in the 2026-11-15 wiring audit; `exact.capture_pair` is unchanged.) Negative results distinguish bounded incompleteness. Capture timestamp is the first proven availability; no historical publication is invented. The real Apple pair capture is page 4 of 5 under `docs/evidence/parallel/agent-2/security/`; pair lookup is not a listing/ownership inference.

A SEC N-PORT search-index transcript retains a small partial observation of direct Apple shares in Direxion Daily AAPL Bull 2X Shares, report date 2026-01-31. Two documented records connect SEC series/class to ticker and ticker to ISIN. `/v1/intelligence/disclosures/aapu` calls deterministic look-through with availability at transcript retrieval (2026-11-15); Markets displays date restrictions, direct equity and unresolved remainder. The fund has swaps and leverage: direct equity is not total economic exposure and the unresolved remainder cannot be interpreted as zero exposure. This is a partial indexed transcript, not original raw XML; the source URL and both mapping sources are in the JSON artifact. Generic CSV/N-PORT parsers require source hash, explicit fund ISIN mapping and exact constituent ISIN; no ticker or fuzzy-name joins. They are not yet acquisition/persistence/UI pipelines for arbitrary funds. Parser inputs must have independently proven mapping and rights.

Coin Metrics Community daily BTC/ETH aggregate through `/v1/intelligence/coinmetrics/{asset}` validates provider identity/units/time and stores immutable session-owned raw capture. The real BTC response is preserved under evidence with Creative Commons BY-NC attribution. The runtime is disabled unless `APLOMB_COINMETRICS_NONCOMMERCIAL=1` represents confirmed entitlement; commercial use requires rights. Observation date is not publication/availability, so only capture time is asserted. `/v1/intelligence/sec-structured` parses recent structured-disclosure RSS, limits size and links, rejects DTD/entities, retains session-owned source capture and requires `APLOMB_SEC_CONTACT` in descriptive `Organization email` form. SEC access has returned 403 and live RSS capture remains unvalidated. Both sources are surfaced in Markets with explicit unavailable states. Source URLs use HTTPS and redirects are disabled.

`SOURCES.csv` maps all assigned SRC/MASTER identifiers, including MASTER-006 Coin Metrics, MASTER-017 SEC Structured RSS and MASTER-022 SEC Data Library. It distinguishes missing engineering from verified source access/rights blockers. Most worldwide sources, exchange-aware instrument master, live financial statements/news/ownership/disclosures, regional coverage, richer dated relationship graphs, and arbitrary-fund end-to-end ingestion remain unimplemented; a partial adapter, a link or a test fixture is not represented as full integration. BlackRock terms restrict automated copying and redistribution without written permission; the exploratory iShares response was removed from the branch. SEC raw XML access returned 403; no access bypass was attempted.
