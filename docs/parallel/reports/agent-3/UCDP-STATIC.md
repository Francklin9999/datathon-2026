# UCDP GED static release

**Status: captured in the application provider bundle.** SRC-130 and MASTER-052 identify the Uppsala Conflict Data Program (UCDP) [Georeferenced Event Dataset (GED), global version 26.1](https://ucdp.uu.se/downloads/). Its [codebook](https://ucdp.uu.se/downloads/ged/ged261.pdf) says this release covers 1989-01-01 through 2025-12-31. It records events of organized lethal violence under UCDP's definitions and coverage criteria. It is not a real-time feed or a complete account of all violence. The separate UCDP API requires a token and was not used.

The staged sample selects Ukraine rows with `year=2025`, valid coordinates and dates, and nonnegative ordered fatality estimates; the 100 latest by `date_end` are selected, with descending numeric event ID as the tie breaker. The archive has 417,968 rows; 7,504 match the country and year, and 17 were rejected by the fatality ordering check because the source's `high` value is below `best`. The remaining sample covers event end dates 2025-12-27 through 2025-12-31. It is intentionally incomplete and must not be treated as a count for the year or country. Fatality values are source estimates. The 100 selected events have date precision 1; the location precision codes are 1 (16), 2 (47), 3 (8), 4 (22), and 5 (7). Codes 3 and 4 represent administrative divisions and 5 can represent a linear feature or fuzzy area: these coordinates are coded representative points, not necessarily exact event locations. Consult the codebook for the full meanings. `observedAt` uses midnight UTC on the earliest possible date as a date placeholder, not a known event time. Capture-time availability gating applies.

UCDP's [downloads page](https://ucdp.uu.se/downloads/) licenses the datasets under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and asks users to cite the listed publications. This sample adapts the source by filtering, validating, selecting and normalizing fields.
