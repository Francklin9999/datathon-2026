# Bounded BLS public capture and Census access check

SRC-098 is integrated as `world_bls_us_cpi_2024`: 12 monthly 2024 observations from the anonymous BLS publicAPI v2 endpoint for `CUUR0000SA0`. This is CPI-U all-items, U.S. city average, not seasonally adjusted, index 1982-84=100. The index is not an inflation rate. The source reference month uses its first day as a display anchor; source publication and vintage availability are unproven. Capture-time gating excludes these records from earlier historical views.

The collector `backend/aplomb/world/providers/bls_extra.py` fixes its endpoint and year, refuses redirects, limits responses to 100 KB, uses a 20-second request/read deadline and at most three attempts, and validates status, series identity, monthly periods, positive finite values, period names, duplicates and footnote shape. Publication uses the existing immutable raw and normalized SHA-256 capture mechanism. Runtime consumes the capture locally without requesting BLS. Macro mode and the USA country/search filters return the observations. National statistical geography has no fabricated point coordinates. The passport provides source, limits and attribution; no issuer relationship or financial impact is inferred.

The captured BLS numerical government statistics retain attribution and no-endorsement wording. Third-party content, images and marks are not captured. The anonymous API succeeded.
