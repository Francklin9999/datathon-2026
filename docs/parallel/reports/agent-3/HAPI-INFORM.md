# HDX HAPI INFORM Risk Index 2025

The project contact email configured in Git was used, with application name `Aplomb Datathon 2026`, to request a HAPI v2 app identifier through the official `GET /api/v2/encode_app_identifier` endpoint. The identifier is saved only in ignored `.env.world-data.local` with file mode 0600. It is not in Git, a source URL, the capture manifest, raw payloads or this report. The capture adapter reads `HAPI_APP_IDENTIFIER` from the process environment or that ignored local file for explicit manual refresh; ordinary runtime API reads use the immutable capture without contacting HAPI.

The selected official HAPI v2 endpoint is `coordination-context/national-risk?limit=250&offset=0`. It returned 191 country records, all from the 2025 INFORM Risk Index HDX resource `11a789fc-e9b3-48c6-b1e6-260959799220`, with no next page implied by the response being shorter than the requested limit. The linked HDX `package_show` metadata identifies the underlying dataset as `inform-risk-index` and declares licence `cc-by` (Creative Commons Attribution International). The HAPI coordination/context guide identifies INFORM as the data provider, annual update cadence and national composite meaning. These original bytes are hashed in the immutable capture; the credential-bearing request URL is recorded with the identifier redacted.

Dataset: `world_hapi_inform_risk_2025`. Version: `world_hapi_inform_risk_2025-2026-11-15-8ac081f2a1be58b4`. The 191 records retain source ISO3 countries, rank, risk class, overall risk score and three component scores, missing-indicator fraction, indicator recentness, resource ID and annual reference period. Scores are a national humanitarian risk composite on a 0–10 scale. No disaster event, forecast, point location, issuer exposure or financial risk inference is made. January 1 is a display anchor; the capture retrieval time gates historical availability because original vintage availability is unproven.

The versioned loader verified the raw and normalized SHA-256 and all 191 country codes and values. The real HTTP observations route returned 200 with 191 matching records in hazards mode and `location=null`. The new dataset is registered in the catalogue and passport descriptors. HAPI's other data categories may aggregate different upstream licences and remain outside this capture.
