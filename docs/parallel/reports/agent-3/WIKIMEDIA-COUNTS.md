# Wikimedia attention counts — SRC-126

Implemented a bounded anonymous Wikimedia Analytics API capture of seven daily English Wikipedia pageview counts for each of the Canada, Japan and Brazil articles, 2026-10-01 through 2026-10-07. The news observation list consumes 21 saved source records through the existing service and exposes the source URL, reporting date, count, attribution and limitations. These counts describe topic attention; they do not establish reader geography, sentiment, unique people, event confirmation or financial effects. Country and coordinates remain absent.

Capture: `world_wikimedia_topic_pageviews-2026-11-15-5d0fb5273c198afa`, retrieved `2026-11-15T17:38:59Z`, normalized SHA-256 `5d0fb5273c198afa645d2c57a41830c694a314938d627137b0366612c1d75721`.

The manifest records raw checksums for three actual API responses and a captured copy of the Wikimedia licensing page. Its **Analytics Datasets** section says “All Analytics datasets are available under the Creative Commons Zero (CC0) public domain dedication, unless otherwise specified.” This integration retains numeric analytics and topic identifiers; it does not republish article bodies or images. Licence source: <https://dumps.wikimedia.org/legal.html>.

`python -m aplomb.world.providers.public_counts_extra` performs the capture. Requests are limited to four fixed HTTPS URLs, refuse redirects, wait 0.5 seconds between documents, use 20 second timeouts, cap each payload at 500 kB, and permit only two attempts for temporary failures. The parser requires exactly seven complete dates, fixed project/access/agent/article dimensions, unique dates and nonnegative integer counts. Empty or malformed captures fail before immutable publication. No network request runs from the application observation endpoint.

Direct validation used the actual saved capture through `WorldServiceImpl.observations`, `provider_passports`, `DatasetPassport`, and checksum-verified snapshot loading: 21 news observations, an `in_use` passport with 21 rows, no geographic markers, and zero rows at `asOf=2026-10-31`. Evidence: `docs/evidence/parallel/agent-3/wikimedia-pageviews-runtime.json`. No new tests were added, per current user preference.

Changed paths: new provider module; new immutable provider directory; additive enum in `backend/aplomb/contracts/catalog.py`; descriptor in `backend/aplomb/datastore/passports.py`; provider ID in `backend/aplomb/world/passports.py`; mode and factual summary in `backend/aplomb/world/service.py`; this report and runtime evidence. Shared enums/schema mirrors must be regenerated by the integrator with the other source additions.

Remaining scope: the selected sample is not all Wikimedia articles, projects or history, and refresh is manual. No historical vintage is proven; availability is gated at retrieval. No browser check was performed for this addition; the existing generic observation list consumes the backend response.
