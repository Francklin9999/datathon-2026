# World Bank WGI country score capture

SRC-147 is enabled as `world_wgi_political_stability_2024`. The bounded official World Bank WGI source 3 API returned one 2024 political-stability governance-score indicator (`GOV_WGI_PV.SC`), with 216 source records; 207 had a numeric 0–100 score and a source ISO3 code and were published. Nine blank-code or nonnumeric records were excluded. Captured on 2026-11-15 as `world_wgi_political_stability_2024-2026-11-15-3bf699338c906296`. The manifest stores exact API request URLs, source and indicator metadata, the source data page and the World Bank data-licensing page as raw SHA-256-verified responses, alongside normalized rows.

The [World Bank data-licensing page](https://datacatalog.worldbank.org/public-licenses) states that CC BY 4.0 is the default for datasets produced by the World Bank itself and distributed as open data, with attribution and disclosure of modifications. The capture uses the World Bank Worldwide Governance Indicators source rather than third-party linked material. Each observation carries World Bank attribution and indicates Aplomb's adaptation. The source's WGI research series is composed from surveys and assessments; the 0–100 score is an estimate, not an observed conflict, current political event, or financial-risk probability. The World Bank API source update was 2026-09-25. Original 2024 publication vintage is not proven, so the rows are available only from capture time in historical queries.

The 2024 year is an annual reference period. January 1 is a display anchor, not a measurement or release timestamp. Geography is the source country or territory code, without an invented point. This one-indicator sample is not complete WGI coverage, and no issuer or portfolio relationship is asserted. The runtime observation list and dataset passport expose the source and limitations. Refresh manually with `PYTHONPATH=backend .venv/bin/python -m aplomb.world.providers.ingest --source wgi`. The collector bounds a single API page, validates source and indicator IDs and score range, rejects redirects outside its fixed host allowlist, and stores immutable raw and normalized hashes. No new tests were written.
