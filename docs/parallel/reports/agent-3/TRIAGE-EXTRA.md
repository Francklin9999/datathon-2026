# Additional source access and reuse triage

Checked 2026-11-15. This is a read-only assessment, not an implementation or a blanket license determination. The IDs below are ledger aliases for the named source; similar names do not imply identical datasets. The user excluded paid plans and deferred paths requiring login, keys or approval. Public access is not itself permission to republish third-party content.

## Engineering candidates and conditions to resolve before publication

| IDs | Source and evidence | Classification and next step |
| --- | --- | --- |
| SRC-094, MASTER-036 | [BIS SDMX API](https://stats.bis.org/api-doc/v2/) exposes public statistics; [BIS data terms](https://data.bis.org/help/legal) allow use and reproduction with BIS source credit, no misleading endorsement and an unofficial-translation notice where applicable. A commercial product may include the statistics only if inclusion causes **no additional charge** to users. | Engineering backlog **conditional on product compliance** with those terms. Select a series, verify its live response and dimensions, record its vintage and attribution, then implement bounded capture and consumption. If the product charges extra for this data, permission is required; API access does not waive the condition. |
| SRC-130, MASTER-052 | [UCDP downloads](https://ucdp.uu.se/downloads/) state CC BY 4.0 and require citation of the relevant publications. Its GED 26.1 [CSV ZIP](https://ucdp.uu.se/downloads/ged/ged261-csv.zip) returned HTTP 206 for a 128-byte anonymous range request on the check date (39,122,522 bytes total). [UCDP API](https://ucdp.uu.se/apidocs/) requires an individually requested token. | **Static versioned download is an engineering candidate** distinct from the deferred API. Pin version and hash, preserve citation and codebook, validate dates, geography and release scope, and capture to a staging area. Range response does not validate the whole file or prove implementation. API remains deferred under the user's instruction. |
| SRC-157, MASTER-063 | [NASA GIBS](https://nasa-gibs.github.io/gibs-api-docs/) provides open imagery services and requests a specific GIBS acknowledgement. [NASA Earthdata guidance](https://www.earthdata.nasa.gov/engage/open-data-services-software-policies/data-use-guidance) says unmarked NASA-led mission data are CC0 and requests attribution; non-NASA datasets and labeled restrictions have separate terms. | Engineering candidate for a **specifically selected, verified NASA-owned layer**. Verify its layer metadata, terms and no-login access; add required credit, dates and tile/WMTS behavior. Do not assume every GIBS layer has identical rights. |
| SRC-213 | [ADS-B.lol API documentation](https://www.adsb.lol/docs/open-data/api) says the API is available to everyone under ODbL 1.0, with 500 requests/day per IP without a key; higher quotas require a key or other arrangement. | Candidate for bounded anonymous experimentation, subject to **ODbL database attribution, share-alike and produced-work obligations** and suitability of 500/day for the actual product. Review the exact architecture and whether the resulting database triggers sharing obligations before redistribution. Build retries and rate limiting; no keyed or sponsor plan in this scope. This is aircraft positions, not a complete global aviation census. |
| SRC-217 | [OpenFlights data](https://openflights.org/data.php) identifies database reuse under ODbL. | Engineering backlog subject to attribution and applicable database share-alike review. It is a historical airport database; check release vintage and suitability before capture. See `GEODATA-EXTRA.md` for prior findings. |

Availability of a free mapping service alone does not prove blanket reuse rights. |
