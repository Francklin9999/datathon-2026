# Handoff template

Copy to HANDOFF.md and fill with actual results.

- Agent / branch / final commit:
- Baseline SHA:
- Requirement matrix and source matrix paths:
- Implemented user-visible behavior:
- Changed files and shared-file edits:
- Exported interfaces / examples / consumer dependencies:
- Source access, rights, versions, dates, capture hashes and limitations:
- Commands executed and actual exit codes/results:
- HTTP/browser/model/AWS evidence (distinguish real/scripted/offline):
- Security/financial/temporal/ownership checks:
- Remaining unimplemented work:
- Genuine external blockers and owner actions:
- Integration/migration/rollback notes:
- Commit/push result:

Do not declare the entire project complete. Do not replace unresolved engineering with a vague credential blocker.
