# EPA ECHO facility search

**Status: captured for evidence; not enabled in the application.** SRC-220 and MASTER-091 refer to EPA ECHO. The no-login [facility search API](https://echo.epa.gov/tools/web-services/facility-search-all-data) was queried for ZIP 10004, with its first page limited to 100 results and its map response included. The captured response reported 337 matching records; this sample is not a full ZIP, city or national inventory. Seven of the 100 returned records display a ZIP other than 10004; the search filter does not guarantee the displayed ZIP. The 100 facility rows retain the 12-digit EPA FRS RegistryID and join map points by that identity and name. All 100 have a map point in this capture. Coordinates are source facility points, not verified boundaries; `accuracyMeters` is the value provided by EPA, not an independent accuracy guarantee. No issuer or security link is established.

EPA's [disclaimer](https://www.epa.gov/web-policies-and-procedures/epa-disclaimers) states EPA-produced geospatial data are public domain by default unless otherwise specified; it also says permission is needed for copyrighted material produced outside EPA. ECHO contains data from multiple governmental sources, so this general statement does not establish blanket commercial reuse rights for every underlying field. This capture remains staged pending dataset-specific reuse review. ECHO compliance status reflects the agency's records and is not proof of current compliance or absence of violations. Original historical availability is unknown; rows are usable only from capture time.
