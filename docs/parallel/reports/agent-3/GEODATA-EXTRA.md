# GeoBoundaries France ADM1 capture

`SRC-154` / `MASTER-059`: a bounded, no-login sample has been implemented in `backend/aplomb/world/providers/geodata_extra.py`. It captures the API metadata and a pinned geoBoundaries simplified GeoJSON release, publishing 13 metropolitan French regions into the runtime provider bundle. `/v1/world/observations` exposes the polygons in infrastructure mode, with country, search, paging and polygon intersection for viewport filters. World Explorer selects and draws each source boundary without inventing a map pin; the source passport retains scope, license and capture-time availability. The source metadata specifies 2022, IGN-F, and Etalab Open License 2.0. geoBoundaries publishes its datasets under CC BY 4.0 and requests attribution ([geoBoundaries terms and citation](https://www.geoboundaries.org/index.html)); the capture manifest and each observation attribute IGN-F and geoBoundaries and identify adaptations. See also [source metadata](https://www.geoboundaries.org/api/current/gbOpen/FRA/ADM1/) and [IGN dataset terms](https://geoservices.ign.fr/sites/default/files/2021-11/IGNF_ADMIN_EXPRESS_3-1.html). The license applies to this specific release; it should not be assumed for other countries or layers without reviewing their metadata.

The sample excludes overseas regions and uses simplified polygons unsuitable for surveying or legal boundary determinations. It supplies polygons without inventing center points, and capture time is the earliest proven availability. It is neither a complete global boundary dataset nor a historical vintage. The metadata URL is current, while geometry is pinned to release `9469f09`; collection fails closed if its URL, license, scope, year or count changes and requires review before a new release is captured.

Captured at `2026-11-15T17:17:04Z`: 13 observations, normalized SHA-256 `f15e84950b668c542e77a3de83077b6e1f45b58323d28e68be6f33bdced31ce4`; the manifest contains both raw hashes. Manual verification loaded the snapshot with integrity validation and confirmed that a 2020 as-of query returns no rows. Reproduce with `PYTHONPATH=backend .venv/bin/python -m aplomb.world.providers.geodata_extra --directory <capture-directory>`.

Other explored sources: the USGS FDSN historical earthquake catalog is already integrated; a separate bounded USGS weekly GeoJSON feed was later captured under SRC-171 and MASTER-066; see `QUAKE-FEED.md`. OpenFlights says its database is under ODbL with attribution and derived database conditions; its historical dataset and share-alike terms need review before integration ([terms](https://openflights.org/data.php)). The Canada geoBoundaries ADM1 simplified download is approximately 26 MB, exceeding this collector's 4 MB cap; the separate Canadian license and geometry need a purpose-built capture. These findings do not establish access or reuse terms for other ledger rows.

Runtime integration was manually checked through snapshot integrity loading, the observation contract, France viewport intersections, and passport loading. No tests were added. The shared provider CLI accepts `--source geoboundaries`; capture metadata remains release-pinned.
