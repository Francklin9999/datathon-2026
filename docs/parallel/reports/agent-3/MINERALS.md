# USGS Mineral Commodity Summaries 2026

The public [ScienceBase release](https://www.sciencebase.gov/catalog/item/696a75d5d4be0228872d3bf8) supplied its item metadata and `MCS2026_Commodities_Data.csv` without a key. The item marks the work [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), and identifies a 2026-02-06 publication date. The bounded adapter in `backend/aplomb/world/providers/minerals.py` captured the item metadata and CSV as raw, checksum-verified inputs and normalized 74 numeric 2025 country mine-production values for lithium, cobalt, copper, rare earths, nickel and natural graphite. Capture: `world_usgs_minerals-2026-11-15-838ee81f36ae151e`. The selected source rows include 88 country or aggregate entries; withheld, missing and “Other countries” entries are omitted, never converted to zero. All selected countries use an explicit ISO3 mapping; unmapped countries make the capture fail.

Values retain their source unit, source text and notes. Country records have no latitude or longitude. They are national estimates, not specific mines, company output, security relationships or current resource disruptions. The annual reference year and release's calendar publication date do not establish the original publication time of every value; the snapshot is first usable at its 2026-11-15 capture time and is excluded from earlier as-of queries.

Refresh manually with `PYTHONPATH=backend .venv/bin/python -m aplomb.world.providers.minerals`. The ingestion transport permits only the ScienceBase host for both metadata and its declared CSV, caps each response at 5 MB, and validates the declared file size, schema, rights string, data scope and units. The immutable manifest records hashes, row count, limitations and two raw capture URLs. The source IDs are SRC-199 and MASTER-086.
