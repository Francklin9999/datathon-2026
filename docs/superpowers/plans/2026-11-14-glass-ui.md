# Glass UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole Aplomb web app as a calm, animated glass UI with dark and light themes, and rebuild Home as a glass dashboard fed only by real API data.

**Architecture:** Plain global CSS split into focused files driven by theme tokens on `html[data-theme]`; a tiny inline boot script avoids theme flash. `motion` is used only in small client components (sliding pills, drawer presence); every other effect is CSS. Pure geometry and keyboard logic lives in `web/src/lib/ui/*.ts` and is unit-tested with the existing `node:test` runner.

**Tech Stack:** Next.js 16.4.6 (static export), React 19.3.1, TypeScript 5.9.3 strict, `motion` 14.14.0 (`motion/react`), `lucide-react` 1.73.0, `@fontsource-variable/fraunces` 5.3.0, `@fontsource/ibm-plex-sans` 5.3.0, `@fontsource/ibm-plex-mono` 5.3.0.

**Spec:** `docs/superpowers/specs/2026-11-14-glass-ui-design.md` (reference image in `docs/superpowers/specs/assets/`). Read it before any task.

## Global Constraints

- No changes under `web/src/state/`, `web/src/api/`, `web/src/contracts/`, `web/src/lib/*.ts` (existing files), `backend/`, `contracts/`.
- Every value that has a `factId` stays a `FactChip`; values without one are plain text. No invented or decorative figures.
- Status is never colour-only: keep icon + text in `StatusBadge`, `VerdictBadge`, `RunStatusBadge`.
- Text contrast WCAG AA (4.5:1 body, 3:1 ≥ 18.66 px bold / 24 px) on glass, in **both** themes.
- Interactive targets ≥ 44 px; focus ring `2px solid var(--focus)` with 2 px offset (gold in both themes).
- `prefers-reduced-motion: reduce` → no non-essential animation; `prefers-reduced-transparency: reduce` and `@supports not (backdrop-filter: blur(1px))` → opaque surfaces.
- Disclaimer and `dataAsOf` stay visible on every page; static export only (no server runtime, no build-time network).
- Exact dependency versions (no `^`). Motion tokens (Arc library, MIT): ease-enter `cubic-bezier(0.16, 1, 0.3, 1)`, ease-exit `cubic-bezier(0.7, 0, 0.84, 0)`, durations 120/160/240/480 ms, spring `snappy` = `{ type: 'spring', visualDuration: 0.26, bounce: 0 }`, `smooth` = `{ type: 'spring', visualDuration: 0.4, bounce: 0 }`.
- Hover/press feedback = colour/glow only, no scale on hover; press scale ≥ 0.98.
- Checks that must stay green: `npm run typecheck --workspace web`, `npm run test:contracts --workspace web`, `npm run build --workspace web`.
- Commits go to branch `feat/glass-ui`, path-scoped (`git add <paths>`, never `git add .`).

## Review Focus

1. Theme preference missing, corrupted or storage blocked (private window) → follows the system theme, never throws, no flash of the wrong theme. *(Task 1 test `resolveTheme`)*
2. French and long labels (window "Depuis le début de l’année", long profile names, long KPI captions) → wrap or truncate inside their glass box, never widen the page at 375 px. *(Task 3 `windowShortLabel` test + Task 6 375 px check)*
3. Allocation with a single group, zero/negative weights or weights not summing to 100 → donut draws a full ring or proportional arcs, never `NaN` paths. *(Task 4 `donutArcs` tests)*
4. Performance series with exactly 2 points, all-equal values or no benchmark → chart renders without division by zero; crosshair finds the nearest point. *(Task 4 `chartScale`/`nearestIndex` tests)*
5. Reduced motion or an animation that never runs (background tab, screenshot) → every element is fully visible: animated start states exist only inside `@keyframes`, never as base styles. *(Task 5 CSS check)*
