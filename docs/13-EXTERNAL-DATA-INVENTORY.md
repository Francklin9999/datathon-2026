A bounded live probe on 2026-11-15 used the existing `PublicHTTP` transport and the project URL in its user agent. SEC companyfacts for CIK 0000320193 returned HTTP 403 (HTML); GDELT DOC search timed out with an eight-second request budget. These observations do not establish a working provider integration.

The company-facts tool checks that the response CIK matches the requested company, validates filing and period dates, accepts only explicit USD/CAD units, and requires a recognizable form and accession. It omits malformed, future-filed and future-period records rather than trying to infer their meaning. This intentionally excludes forward-looking reporting-period facts; only historical reported figures are considered. The ledger independently verifies each selected numeric source row. Filing dates have day precision and do not establish intraday availability; external research remains disabled for historical replay.
