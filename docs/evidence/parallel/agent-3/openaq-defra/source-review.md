# OpenAQ: bounded DEFRA station capture

Access checked 2026-11-15: the OpenAQ v3 API accepted the configured API key. The key is sent only in the `X-API-Key` header to the fixed OpenAQ HTTPS endpoints; it is not stored in the capture. The service's [terms](https://docs.openaq.org/about/terms) require reviewing each upstream provider's terms.

The selected [York Bootham location 742](https://api.openaq.org/v3/locations/742) identifies DEFRA as provider 169, Great Britain as its country, and UK Open Government Licence (id 34) from 2016-01-30 without an end date. The associated sensors identify PM2.5, PM10, NO2 and ozone in µg/m³. DEFRA's [data terms](https://uk-air.defra.gov.uk/data/) permit copying, publishing, distribution, adaptation and commercial use under the Open Government Licence, subject to its specified attribution. The data and application display include that attribution and the [licence link](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/). Captured location metadata and DEFRA terms are retained as checksummed raw evidence with the data.

The snapshot contains 96 hourly measurements for 28 March 2026 UTC, four sensors at one station. OpenAQ reports the station's last observation on 29 March 2026, so this is historical data, not a current air-quality feed or a representative picture of the UK. Each row carries the source period, concentration, units, flag state and exact location. It is not an air-quality index, health assessment, or financial exposure claim. Historical replay is gated at the capture time because the original availability of this version was not established.

The rights conclusion applies only to this station and period. OpenAQ aggregates providers with distinct terms; other locations require independent checks before publication. The AirNow provider was also inspected: its [API documentation](https://docs.airnowapi.org/) describes its data as preliminary and intended for air-quality index reporting and forecasting. No AirNow data is included.
