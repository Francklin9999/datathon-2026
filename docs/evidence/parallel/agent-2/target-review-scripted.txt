Roles: who may do what
Planner

Model work

Reads the request and the profile, then names the scenarios, calculations and research questions to run, or asks one clarifying question. After an objection from the rule check it decides what else to test.

Researcher

Model work

Runs the research questions with the research tools and returns evidence with citations, not conclusions. A page that is not saved as evidence cannot be cited.

Quant

Deterministic code

Deterministic code. Computes the mandatory metric set and the calculations the plan asked for. Every number leaves it as a fact with its dataset, method and row counts.

Allowed tools (10)
Risk officer

Deterministic code

Deterministic code. Evaluates every enabled rule for every scenario and computes the verdicts, the funding comparison and the largest size before the first rule conflict. Runs on every decision; the model cannot skip it.

Model work

Drafts the explanation using tokens that refer to facts, rules and evidence. It receives the ledger and the rule checks; it computes nothing and decides no verdict.
