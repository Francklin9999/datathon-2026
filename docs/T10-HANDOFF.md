# T10 Ledger and audit handoff

Implementation: `backend/aplomb/ledger/{core,audit}.py`; public imports from `aplomb.ledger`.

## Integration

```python
ledger = Ledger(run_id, as_of, clock=lambda: "2026-11-14T20:00:00Z")
fact_id = ledger.add_fact(fact_mapping)  # public Fact fields, generated id/key/display/createdAt optional
ledger.register_document(DocumentRef(reference, original_text, canonical_source_url, run_id))
evidence_id = ledger.add_evidence(evidence_mapping)  # documentRef resolves registered document
brief = audit_and_sign(ledger, draft, lang="en", model=actual_writer_model,
                       rule_checks=checks, review=review_adapter,
                       guardrail=guardrail_adapter, rewrite=rewrite_adapter,
                       historical=True)
```

`draft` has exactly `sections`. Each section has exactly `id`, `title: {en,fr}`, and `sentences`. Each sentence has exactly `id` and `template`. Example template: `Observed value {{fact:F-001}}.`. Raw numeric displays, unknown references/directives, malformed braces, duplicates, and unsupported quotes are rejected or struck. Titles are generated by code; supplied titles cannot introduce unaudited claims. Required sections are `facts`, `assumptions`, `limits` with meaningful surviving content. Trusted code appends cited fact limitation codes.

`review(sections: list[BriefSection], view: LedgerView) -> ReviewResult(model, findings=[], relations=[])` is required and must represent an actual model call. Findings use the public `ReviewFinding` contract. `Relation(sentence_id, left_fact_id, operator, right_fact_id=None, literal_token=None, ambiguous=False)` supports `<`, `<=`, `>`, `>=`, `==`, `!=`. Literal tokens must be exact existing fact tokens, never arbitrary model numbers. Operands must be cited in that sentence and have identical unit, currency, period, and window. Ambiguous relations fail; recognized comparison prose without extraction is struck. The model still owns semantic extraction and unsupported interpretation detection.

`guardrail(text) -> GuardrailResult(actual_id, action)` is optional when unconfigured; an explicitly configured adapter that fails or returns blocked/masked prevents signing. The report records actual configuration/action. A blocked error carries a fixed refusal section rather than the unsafe original draft as ordinary output. A production caller should preserve its original marked audit demonstration separately when authorized.

`rewrite(draft, report) -> draft` runs at most once for mandatory structure or conflict/tension assumptions coverage. Changed sentences require fresh IDs. All checks and model/Guardrail callbacks run again. Unavailable required review is an `AuditFailure`, never a fabricated passed audit.

`AuditFailure` carries `.report` and `.sections` where an audit was constructed. Parse/provider failures can have no report. Signing returns public `Brief`, freezes the ledger, and detects callback-time mutation. `Ledger.export()` and getters return deep copies. `render_text()`/`render_html()` omit strikes normally; `render_html()` escapes all source/model text and can include visibly struck demonstration content explicitly.

## Provenance and persistence

`add_fact` ignores supplied verification declarations and records only its actual code provenance checks. It derives FactKey from metric/subject/variant/window, returns the existing ID for semantically identical same-key registration (ignoring only ledger-owned allocation/display/timestamp/verification outputs), rejects changed value or provenance under the same key, validates existing same-run dependency IDs, and uses parsed UTC timestamps for max input availability. IDs expand past `999`. Research-authored declarations stay unverified. Source/method existence validates provenance structure, not external source correctness or the transport used by an upstream producer.

`DocumentRef` is frozen, stores original text and run ownership, and exposes `content_hash` (SHA-256 of original UTF-8). Documents cannot be replaced under an existing reference. Evidence verification requires matching same-run reference/URL and quote presence after whitespace normalization, preserving accents and punctuation. The original text remains unchanged. A08 does not certify the publisher's claim as externally true.

`add_quote_figure(fact, evidence_id, *, value_text, unit_text)` verifies numeric research figures with a verified quote, matching source URL, exact numeric value, adjacent explicit recognized unit, and unambiguous decimal notation. It records the actual A08 check and document hash and sets `M_QUOTE_VERBATIM`. Ambiguous grouping notation and unit conversions are refused. Research attention ratios require registered source facts and an actual deterministic computation; the ledger does not invent that computation.

`checkpoint()` and `Ledger.restore(run_id, as_of, state, clock=...)` preserve exact fact/evidence IDs and checks, frozen state, source text and hashes. Restore validates IDs, graph, cutoff, keys, bundle integrity and document integrity. These are internal storage APIs, never model/tool inputs. Bundle hashes are integrity checks, not authentication of untrusted persisted state.

Canonical bytes are UTF-8 JSON of `{facts,evidence}` only; recursive sorted keys, Unicode preserved, no insignificant whitespace, finite numeric values. Optional fields absent in shared contract objects remain absent. SHA-256 changes with any value/provenance change; sentences are outside the hash. The injected clock supplies `signedAt`. Historical checks reject unknown temporal availability and all modes reject future availability using the next-day-exclusive UTC boundary; timeless user/assumption sources remain allowed.

## Sabotage

`fork_for_sabotage(parent_run, parent_ledger, child_run_id)` requires a succeeded decision parent with matching frozen bundle and distinct child identity. It deep-copies pinned facts/evidence; mutations cannot change the parent. `sabotage_caught(report, sections, injected_sentence_ids)` only returns true for an actual struck injected sentence with an actual failed check. Empty injection IDs mean writer refusal/no injected lie, hence no catch. T08 owns the real writer invocation, exact instruction storage, demonstration label and result assembly.
