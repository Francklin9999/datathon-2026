Check primary documentation and ToS before production use. A subset of entries are bulk downloads, public reports, or sandboxes rather than REST APIs.

## Implementation filter

1. Favor official global statistics, SEC, GDELT, BoC, FRED/ALFRED, World Bank, EONET, USGS, GDACS, and EIA/Ember for initial integrations.
2. Build source adapters behind a common `source_id`, `observed_at`, `published_at`, `available_at`, `retrieved_at`, `license`, `instrument_id`, `geo_id`, and `data_version` record.
3. Use source-specific validation, bounded concurrency, retries, and cache; no API keys in the browser.
4. Never invent geographic or instrument relationships. Preserve provider provenance.
5. For historical replay use publication/availability date (and actual vintages), not merely observation date.
6. Check public display terms separately from free-call eligibility.
